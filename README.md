Analysis code and result files for the study comparing the dynamics of constructing and
committing to an answer in cortical populations and in transformer-based AI models, using a
recurrent-versus-input demix (subspace state-space identification, N4SID / SubspaceDMDc).

The pipeline asks, on the same footing in both substrates, how much of a population's
moment-to-moment change is generated by its own recurrence versus driven by external input, and
whether the autonomous component strengthens at the moment a decision is committed.

## Installation

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install "git+https://github.com/mitchellostrow/DSA"   # SubspaceDMDc / N4SID
```

The variance-partition read-out (`auto_unique`) is pure NumPy. The autonomous-eigenvalue
read-out (`sdmdc_dom`) requires the DSA package above. Language-model activation extraction
additionally needs `torch` and `transformers` and is best run on a GPU; the deposited result
JSONs let you reproduce every figure without re-extracting activations.

## The instrument

`src/demix.py` provides the two read-outs used throughout:

- `sdmdc_dom(X, U)` — magnitude of the dominant eigenvalue of the latent autonomous operator
  from SubspaceDMDc (N4SID). Validated to recover a known autonomous gain invariant to input
  strength when the input is exogenous; reported for the brain decision data.
- `autonomy_index(X, U)` — variance partition `auto_unique = R²(x'|x,u) − R²(x'|u)`, the
  next-state variance explained by the past state beyond the known input. Robust across substrates.

Both take trajectories `X` of shape `(trials, time, features)` and an aligned exogenous input `U`.

## Reproducing the results

**Synthetic validation (no external data; runs on CPU in minutes):**

```bash
python src/synthetic_validation.py results/inputdsa_synthetic2.json
python src/synthetic_validation_varpart.py results/validate3.json
```

These regenerate the instrument-validation results (Figure 1): exact recovery of a known
autonomous gain invariant to input strength, and the variance-partition controls.

**Figures (from the deposited result JSONs; CPU, seconds):**

```bash
python figures/make_figures.py
```

**Brain analyses** require the public datasets below, downloaded into `data/` and reduced to
per-session population trajectories with the corresponding `extract_*` script, then analysed:

- `src/analyze_ofc.py` — rat orbitofrontal cortex: autonomous-versus-input balance and the
  recruitment of recurrence under inference.
- `src/analyze_commitment.py` — the commitment-locked autonomous attractor (perceptual-decision
  Neuropixels data with per-trial commitment times), commitment- vs stimulus-aligned.
- `src/analyze_entorhinal.py` — primate entorhinal cortex (second anchor).
- `src/analyze_nulls_commitment.py` and `src/analyze_nulls_confidence.py` — the pre-registered commitment and confidence null tests.

**Language-model analyses** (GPU recommended):

- `src/analyze_llm_balance.py` — extracts hidden states for the construction items
  (`data/construction_items.json`) at several fractional depths and computes the
  autonomous-versus-input balance and the inference-versus-control recruitment per model.
- `src/analyze_llm_commitment.py` — the across-layer attractor analogue aligned to the
  logit-lens commit layer.

result of Luo et al. (2025), demixed with the same toolbox; this repository's contribution is the
cross-substrate comparison.

## Notes on hardware and reproducibility

- Random seeds are fixed in the synthetic-validation scripts.
- On many-core CPUs, set `OMP_NUM_THREADS=1` and `OPENBLAS_NUM_THREADS=1` before running the
  per-session loops to avoid oversubscription.
- The model results were computed on a single GPU; the brain and synthetic results run on CPU.
